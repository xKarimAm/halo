# overlay: PLAN

## Job
Wave 3 (W3, Nov 1, after the lean rig). Critical path. Renders Halo inside the Meet page, built from `docs/ui/overlay-mix-b.html` — that file is the **only** token source (colours, glass, icon rings: solid kind-colour disc, black glyph, 1.5px black ring; kind colours sky point / lilac question / mint decision / peach pushback). `OVERLAY-UX.md` governs geometry, timing, fit, motion, accessibility only; where it disagrees on colour or rings, Mix B wins. No halo rings: the name above the head is the halo. Projects `faces.update` boxes to screen with tile rect + video size + object-fit (flip x on the mirrored self tile). Up to 3 glass bubbles per face in `points.upsert.rank` order (the only rank source), fade ~60 s; same `point_id` replaces/moves in place (speaker correction re-send), `replaces` removes the old bubble; `tags.set` is applied in place on the stored point (kind + urgency, same `point_id`) — until Karim picks an urgency-mark draft the bubble shows **no** urgency mark and the popover header shows the word “Urgent” as plain text (Karim's rule: drafts before designs; no placeholder look). DOM built with `textContent` only (Meet enforces Trusted Types). Owns the in-Meet surfaces: badge (option A: floating top-left over the stage; never depends on Meet's bottom-bar DOM) with REC dot, badge menu (hide/show `Alt+H` — bare Alt+H only, key repeat ignored; points language; points-per-face 1–3; Meeting setup…; consent notice…; Recorder switch; Open meeting notes; privacy line), consent dialog (editable bilingual notice — the notice text lives in this lane — ending with **“Copy notice”**, which puts it on the clipboard; the user pastes it into Meet chat themselves; nothing automates Meet's chat DOM), toasts, status chip (incl. the hub's outbox backlog, extension-local), notes-ready toast. Presenter points stay on the camera tile in the MVP; the share surface gets no points. Tiles beyond 6 still render pills in Frame mode; the fit rule folds overflow into `+N`. Captions: treat `captions_rect`'s top edge (from `tiles.snapshot`) as a floor; null → no floor.

## Inputs (contracts consumed)
Socket via hub/Port (⇄ ACK from Overlay; dedupe by envelope id): `points.upsert`, `tags.set`, `speaker.mapped`, `system.status`, `notes.ready`. In-tab (never the socket copy): `tiles.snapshot` + `speaker.active` from the Meet Adapter, `faces.update` from the Face Detector. Thinking state (all in-tab, no contract): `speaker.active` goes false for a tile → light sweep along the name pill until a `points.upsert` lands for that tile or 5 s pass; reduced motion → static dotted underline. (Look marked “draft check with Karim”; the trigger logic is final. No ghost card.)

## Outputs (contracts emitted)
ACKs on the socket (via the Port back to the hub). Nothing else leaves the tab: hide/show + points-per-face are `chrome.storage.local`; the Recorder switch just tells the hub to start/stop `kind=3` chunks (no envelope); a language choice sends Port `set_viewer_lang` to the hub, which re-sends its latest `meeting.context` with the new `viewer_lang` (this module never emits `meeting.context`). Original-quote popover (kind, speaker, timestamp, translated text, original quote with majority-script direction, correction history, “shown N s after pause”, Open in notes → transcript line + recording moment). One chip element per point id, created once; renders only move/reorder/fold/update — never rebuild to measure (OVERLAY-UX §5 no-flash rule).

## Lane (the files it owns)
`extension/src/overlay/**` (+ tests). Runs in the Meet content script (wrapper owned by `hub_capture`).

## Depends on
`contracts`, `hub_capture` (socket fan-out), `meet_adapter` + `face_detector` (in-tab feeds). Urgency-mark render: W2 picks it up Nov 2 after Karim picks a draft (see Doubts).

## Fakes it tests with
Replayer Mode B (recorded backend → extension events) on the Fake Meet page; golden DOM positions vs painted ground truth.

## Done = tests
Run: `npm --prefix extension test`; L3 `npm --prefix rig/fake_meet test`. Concrete cases (diagram box: Replayer B → DOM ±4 px): (1) a Face-mode bubble lands within ±4 px of the head-anchored expectation; Frame-mode (no face, avatar, share, tile >6) pins name + stack inside the tile. (2) Correction with the same `point_id` moves/retexts the same element in place (gold `UPDATED` tag, lifetime restarts); `replaces` removes the old element. (3) A model `tags.set` updates kind/urgency in place; a model tag arriving after a user tag for that point is ignored. (4) Expiry ~60 s, ageing dim at 72%, overflow folds to `+N` under every tile-width cap, no chip touches a face box (200–624 px, EN + AR). (5) Thinking: `speaker.active` false → sweep starts, point arrival or 5 s ends it; `prefers-reduced-motion` → dotted underline. (6) `Alt+H` hides layers (badge stays, reads “Halo · hidden”); `Ctrl+Alt+H` passes through to Meet. (7) Popover: Esc/light-dismiss closes, focus returns, “Open in notes” targets the transcript line; an urgent point shows the plain-text word “Urgent” in the popover header and no urgency mark on the bubble. (8) Consent: “Copy notice” puts the bilingual notice on the clipboard and touches no Meet chat DOM (L3 asserts no chat mutation). (9) Arabic pill renders `lang=ar dir=rtl` at +1 px with the same side/order.
