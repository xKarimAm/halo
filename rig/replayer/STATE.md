# rig/replayer: STATE

## Goal
Implement rig/replayer per its PLAN.md; done ONLY when `uv run pytest rig/replayer -q` passes and the contract tests for replayer pass.

## Key decisions
- Fixture format (owned here) adopts the shape rig/fakes assumed in issue #3, closing it: `asr_script.jsonl` `{stream, speaker, text, lang, ts_start_ms, ts_end_ms}`, `llm_script.jsonl` `{match, response}`. A fixture dir holds `meta.json`, `tab.pcm`, `mic.pcm`, `envelopes.jsonl` (full envelopes + scheduling `ts_ms`), `expected.jsonl`, `faces.jsonl`, the two scripts.
- Committed synthetic fixture lives in this lane at `rig/replayer/fixtures/synthetic/` (generated by `generator.py`, deterministic: silent PCM, fixed UUIDs in envelopes, expected uses fuzzy matching so ids are ignored by the checker).
- Transports are injected callables, so Mode A/B and the golden checker test deterministically against a stub Gateway in-process; the real-Gateway L2 run is the same code with a WebSocket transport once Gateway lands (W1 lane, not built yet — deviation noted in the PR).
- OBS converter uses stdlib `wave` only (16 kHz mono PCM16 WAV in, raw PCM + starter script out).

## Task graph
1. Fixture loader + synthetic generator.
2. Golden checker (ts ±300 ms, fuzzy normalised containment, ids ignored, per-tile order).
3. Mode A (ACK resend same id, virtual clock) + Mode B (ordered sink replay).
4. OBS converter.
5. Tests: golden vs stub Gateway, ACK drop/duplicate, checker teeth, virtual clock, converter.
