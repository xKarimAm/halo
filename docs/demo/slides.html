Why it looks like this

one person, coding agents in parallel, about a week
Keep the live path lightVoice streams live; only finished turns reach Spark.The raw stream through Spark couldn't keep up. The recording goes straight to disk.
Contracts before codeEvery arrow is a JSON Schema, with types for both languages.One agent wrote them first; nobody else coded until they were done.
One agent per laneOne folder, one worktree, one owner. Asks go through GitHub issues.A linter fails CI on cross-imports, so three agents never collided.
One process, one busA modular monolith. No Redis, no LangGraph, no Pipecat.One laptop, one command, few moving parts.
Local, nothing hostedNotes, transcripts and recordings stay on your PC.The extension holds no keys and only talks to 127.0.0.1.
Reliability where neededAcks and resends only on the browser socket.The one place a message can get lost. Saved ~8-10 agent-hours.
Test without a callFake Meet page, fake speech and models, a replayer.Audio to bubble had to pass on the rig before going live.
Measure firstDay-0 probe: Spark's median was 2.7 s, target ~3 s.Fallbacks were set before any module was written.

Try it yourself

Windows, macOS or Linux
  1. You need Chrome, Git, Node.js 22+, a headset and a Meta Model API key.
  2. Clone and run setup
    git clone https://github.com/xKarimAm/halo.git
    cd halo · powershell -ExecutionPolicy Bypass -File .\setup.ps1
    (macOS/Linux: sh setup.sh)
  3. Load the extension chrome://extensions → Developer mode → Load unpacked → extension\.output\chrome-mv3
  4. No call needed uv run python packaging/demo.py, then open http://127.0.0.1:8765
  5. Live Join a Meet with a headset, open Halo, press Start.
